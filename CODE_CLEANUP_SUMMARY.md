## Changes Implemented

### 1. Fixed LARP Code (Fake Implementation)

**File:** `utils/services.ts`

**Before:**
```typescript
// TODO: Replace with real health check aggregation from Tilt API or service health endpoints
const readyCount = resourcesMetadata.filter(() => Math.random() > 0.3).length;

let overallStatus: StackMetadata['overallStatus'] = 'unknown';
if (totalResources > 0) {
  const ratio = readyCount / totalResources;
  if (ratio > 0.9) {
    overallStatus = 'healthy';
  } else if (ratio > 0.5) {
    overallStatus = 'degraded';
  } else {
    overallStatus = 'error';
  }
}
```

**After:**
```typescript
overallStatus: 'unknown',
```

**Rationale:** The code was using `Math.random()` to simulate health checks. Removed the fake logic and now returns `'unknown'` status honestly instead of pretending to do health checks.

## Guidelines Established

### What Was Removed

1. **Obvious comments:** Comments that state what the code already shows
2. **Verbose JSDoc:** Documentation for self-documenting functions
3. **LARP code:** Fake implementations pretending to work
4. **Section markers:** JSX comments labeling obvious sections
5. **Implementation notes:** Comments belonging in documentation
6. **Reference lists:** Comments listing which files use a constant

### What Was Preserved

1. **Complex logic explanations:** Comments explaining WHY, not WHAT
2. **Domain/business context:** Comments explaining domain-specific logic
3. **Non-obvious workarounds:** Comments explaining unusual solutions
4. **Health check endpoint comment:** `// Health endpoint required by TILT_RESOURCE_DEFAULTS.star`

### Examples of Preserved Comments

```typescript
// Health check endpoint (required by TILT_RESOURCE_DEFAULTS.star)
app.get('/health', ...);

// Filter out service-specific domains (long, hyphen-heavy ones)
// Keep only project-level domains (shorter, simpler)

// Give it a moment to fully shut down
await new Promise(resolve => setTimeout(resolve, 2000));
```
