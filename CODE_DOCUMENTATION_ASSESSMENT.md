## Inventory of Problematic Patterns

### 1. LARP Code (Pretends to Do Something But Doesn't)

**Location:** `utils/services.ts:292-305` - `getStackMetadata()`

```typescript
// TODO: Replace with real health check aggregation from Tilt API or service health endpoints
const readyCount = resourcesMetadata.filter(() => Math.random() > 0.3).length;
```

**Problem:** Uses `Math.random()` to simulate health checks. The TODO has been there for an unknown duration. This is **LARP code** - it looks like it does health checking but actually generates fake data.

**Recommendation:** Either:

- Remove the health status entirely and return `unknown`
- Document clearly that this is placeholder behavior pending implementation

## Guidelines for Helpful vs Unhelpful Documentation

### Keep These Comments

1. **Why, not what:**
   ```typescript
   // Health endpoint required by TILT_RESOURCE_DEFAULTS.star
   app.get('/health', ...);
   ```

2. **Complex logic explanation:**
   ```typescript
   // Filter out service-specific domains (long, hyphen-heavy ones)
   // Keep only project-level domains (shorter, simpler)
   ```

3. **Business/domain context:**
   ```typescript
   // Traefik labels can contain domain routing rules we need to extract
   ```

### Remove These Comments

1. **What the code already shows:**
   ```typescript
   // Single discovery call for all resources and stacks
   const discovery = createDiscoveryContext();
   ```

2. **JSDoc that just repeats types:**
   ```typescript
   /** All discovered resources in the project */
   resources: DiscoveredResource[];
   ```

3. **Implementation notes in code:**
   ```typescript
   // Note: Tilt doesn't have a native --quiet flag...
   ```

4. **Empty line explanations:**
   ```typescript
   console.log(); // Empty line between stacks
   ```
