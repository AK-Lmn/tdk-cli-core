## The 5-Step Pipeline

### Step 1: Validate

Check manifest structure. Catch errors before generation.

```python
def validate_manifest(manifest):
    required = ['name', 'port', 'type']
    for field in required:
        if field not in manifest:
            raise ValidationError(f"Missing: {field}")
    
    # Type checking
    if not isinstance(manifest['port'], int):
        raise ValidationError("Port must be integer")
```

**Result:** Invalid manifests caught immediately. No broken configs.

### Step 2: Resolve

Use full system context to resolve conflicts.

**Port Resolution:**
```python
def resolve_port(manifest, ctx):
    requested = manifest['port']
    
    # Check if port already used
    if requested in ctx.port_allocations.values():
        # Auto-assign next available
        return find_next_available(ctx.port_allocations)
    
    return requested
```

**Dependency Resolution:**
```python
def resolve_deps(manifest, ctx):
    deps = manifest.get('dependencies', [])
    
    # Verify each dependency exists
    for dep in deps:
        if dep not in ctx.all_service_names:
            raise ConfigError(f"Unknown dependency: {dep}")
    
    # Detect cycles
    if has_cycle(deps, ctx.dependency_graph):
        raise ConfigError("Circular dependency detected")
    
    # Return topological order
    return topological_sort(deps, ctx.dependency_graph)
```

**Result:** Zero port conflicts. Dependencies always resolve. Cycles caught early.

### Step 3: Generate

Starlark code with full context creates configs.

```python
def generate_for_manifest(manifest, ctx):
```

**Result:** Consistent, context-aware configs.

### Step 4: Verify

Test configs before writing.

```python
def verify_configs(configs):
    # Syntax validation
```

### Step 5: Atomic Write

All configs update together. Never partial state.

```python
def atomic_write(configs):
    # Write to temp directory first
    temp_dir = create_temp_dir()
    for name, content in configs.items():
        write_file(join(temp_dir, name), content)
    
    # Verify all written correctly
    verify_all_exist(temp_dir, configs.keys())
    
    # Atomic move to final location
    atomic_rename(temp_dir, AUTOGENERATED_DIR)
```

**Result:** Never partial updates. Rollback on failure.

## Why Starlark?

### YAML Templates (Level 1)
```yaml
# Static, no logic
services:
  {{name}}:
    ports: ["{{port}}:{{port}}"]
```

### Scripts (Level 2)
```python
# Basic, no context
def generate(service):
    return f"ports: ['{service['port']}']"
```

### Starlark (Level 3)
```python
# Full logic, context, validation
def generate(manifest, ctx):
    if manifest['type'] == 'api':
        return api_config(manifest, ctx)
    elif manifest['type'] == 'web':
        return web_config(manifest, ctx)
    else:
        raise ConfigError(f"Unknown type: {manifest['type']}")
```

**Benefits:**
- ✅ Python-like syntax (familiar to developers)
- ✅ Sandboxed execution (safe)
- ✅ Full programming language (loops, conditionals, functions)
- ✅ Deterministic (same input = same output)

## The Context Object

```python
type Context struct {
    all_services: []        # Every manifest in system
    port_allocations: {}    # Map of service → port
    dependency_graph: {}    # Full DAG
    network_topology: {}    # How services connect
    secrets: {}             # Environment vars
    toolchain_versions: {}  # Bun, Node versions
    previous_configs: {}    # For rollback
}
```

Generators see the entire system, not just one service.

## Auto-Discovery

```python
def discover_services(root_path):
    services = []
    for path in walk(root_path):
        if exists(join(path, 'service.json')):
            services.append({
                'path': path,
                'manifest': load_json(join(path, 'service.json'))
            })
    return services
```

Drop a `service.json` anywhere. Platform finds it automatically.

## Hot Reload

```python
def watch_and_regenerate(service_path):
    watch([service_path + '/service.json'])
    
    on_change:
        manifest = load_json(service_path + '/service.json')
        ctx = build_context()  # Fresh context with all services
        configs = generate_for_manifest(manifest, ctx)
        atomic_write(configs)
        reload_dependent_services(manifest)
```

Change port in `service.json`. All configs update. No restart.
