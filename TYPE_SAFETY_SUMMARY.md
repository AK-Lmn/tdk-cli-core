## Type Safety Patterns Introduced

### Pattern 1: Null-Safe Map Operations
```typescript
// Before
map.get(key)!.push(value);

// After
const existing = map.get(key);
if (existing) {
  existing.push(value);
} else {
  map.set(key, [value]);
}
```

### Pattern 2: Type Predicate Filtering
```typescript
// Before
.filter(s => s.config?.basePath)
.map(s => s.config!.basePath!);  // Non-null assertions

// After
.filter((s): s is typeof s & { config: { basePath: string } } => 
  typeof s.config?.basePath === 'string'
)
.map(s => s.config.basePath);  // No assertions needed
```
