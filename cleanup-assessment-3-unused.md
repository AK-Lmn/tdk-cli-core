## Key Learnings

1. **Always use `--include-entry-exports` flag** - Without it, knip won't analyze library API exports
2. **Verify before removing** - Many items appeared unused but were critical for the CLI
3. **Distinguish CLI vs Library** - The package has dual nature: CLI (bin) and Library (main exports)
4. **Keep internal functions unexported** - Functions used only within their module shouldn't be exported
