## Detailed Analysis

### 1. Library API Exports from `src/index.ts` (INTENTIONALLY KEPT)

**Finding:** 43 exported functions and 46 exported types from `src/index.ts` are flagged as "unused"

**Verification:** These form the **public programmatic API** of the TDK CLI package.

**Evidence:**
- `package.json` exposes `"main": "./dist/index.js"` which is the compiled output of `index.ts`
- The CLI entry point is `cli.ts` (bin), while `index.ts` serves library consumers
- No external consumers currently, but API is designed for programmatic usage

**Decision:** KEEP ALL - These are intentionally exported for:
- External programmatic usage (importing @tdk/cli as a library)
- Type definitions for consumers
- Future extensibility

**Example exports preserved:**
```typescript
// All these are intentionally part of the public API:
export { discoverResources, discoverStacks, ... } from './utils/services.js';
export { runTilt, isTiltAvailable, ... } from './utils/tilt.js';
export type { DiscoveredResource, ResourceConfig, ... } from './types/index.js';
```

### 2. Utility File Exports (VERIFIED AND CLEANED)

#### A. `src/utils/formatting.ts` - `formatAsciiBox`, `printAsciiBox`, `formatSeparator`
**Status:** ✅ CONFIRMED UNUSED - REMOVED

**Verification:**
```bash
grep -r "formatAsciiBox\|printAsciiBox\|formatSeparator" cli/src/commands/
# No results - confirmed not used by any command
```

**Rationale:** These appear to be legacy formatting functions replaced by simpler output methods. The active formatting uses:
- Direct `console.log()` calls with chalk
- `showStep()`, `showDetail()`, `showSuccess()` helpers
- Box formatting via other methods

**Action:** Removed export keywords (functions kept for potential internal use or can be fully removed in future cleanup)

#### B. `src/utils/errors.ts` - `showError()` function
**Status:** ⚠️ USED INTERNALLY - UNEXPORTED (not removed)

**Verification:**
```bash
grep -r "showError" cli/src/commands/ | grep -v "showErrorAndExit"
# No direct imports found
```

**But:** Used internally by `TdkError.display()` method:
```typescript
// In errors.ts:
class TdkError {
  display(): void {
    showError(this.message, undefined, this.suggestions); // INTERNAL USE
  }
}
```

**Action:** Removed `export` keyword, kept as internal function

#### C. `src/utils/port-assignment.ts` - `isPortAvailable`
**Status:** ⚠️ USED INTERNALLY - UNEXPORTED (not removed)

**Verification:** Used internally within the same file by `findAvailablePort()`. Removed export keyword only.

#### D. `src/utils/services.ts` - `discoverAutogeneratedFiles`
**Status:** ⚠️ USED INTERNALLY - UNEXPORTED (not removed)

**Verification:** Used internally within the same file by `getResourceMetadata()`. Removed export keyword only.
