## 3. Consolidation Opportunities

### 3.1 HIGH PRIORITY - Duplicate Type Definitions

#### Issue 1: `CreatableResourceType` duplicates `ResourceType`

**Location:** `cli/src/commands/resource.ts:16`

```typescript
type CreatableResourceType = 'backend' | 'frontend' | 'worker';
```

**Problem:** This is a subset of `ResourceType` from `types/index.ts`:

```typescript
type ResourceType = 'frontend' | 'backend' | 'library' | 'sdk' | 'worker' | 'migrator';
```

**Recommendation:** 
- Derive `CreatableResourceType` from `ResourceType` using Extract
- Or use a const array with type inference

**Fix:**
```typescript
export const CREATABLE_RESOURCE_TYPES = ['backend', 'frontend', 'worker'] as const;
export type CreatableResourceType = typeof CREATABLE_RESOURCE_TYPES[number];
```

**Priority:** HIGH  
**Risk:** LOW - Internal type only  
**Effort:** 5 minutes

### 3.2 MEDIUM PRIORITY - Status Type Consolidation

#### Issue 3: Status type proliferation

**Current status types (6 total):**

| Type | Values | Location |
|------|--------|----------|
| `ResourceStatus` | 'ready' \| 'pending' \| 'error' \| 'unknown' | types/index.ts |
| `StackHealthStatus` | 'healthy' \| 'degraded' \| 'error' \| 'unknown' | types/index.ts |
| `TiltRuntimeStatus` | 'running' \| 'pending' \| 'error' \| 'unknown' | types/index.ts |
| `TiltBuildStatus` | 'ok' \| 'error' \| 'in_progress' \| 'unknown' | types/index.ts |
| `ServiceUrl['status']` | 'running' \| 'stopped' \| 'unknown' | types/index.ts |
| `StatusValue` | Union of above + string \| undefined | types/index.ts |

**Problem:** Multiple overlapping status types make it unclear which to use. `StatusValue` tries to unify them but accepts `string | undefined`, weakening type safety.

**Recommendation:**
Consider creating a hierarchical status system:

```typescript
// Base status types
type BaseStatus = 'unknown' | 'error';
type RuntimeStatus = BaseStatus | 'running' | 'pending' | 'stopped';
type HealthStatus = BaseStatus | 'healthy' | 'degraded';
type BuildStatus = BaseStatus | 'ok' | 'in_progress';

// Specific types derived from base
type ResourceStatus = Extract<RuntimeStatus, 'ready' | 'pending' | 'error' | 'unknown'>;
type ServiceStatus = Extract<RuntimeStatus, 'running' | 'stopped' | 'unknown'>;
```

**Priority:** MEDIUM  
**Risk:** MEDIUM - Affects type signatures  
**Effort:** 30 minutes  
**Note:** Existing `StatusValue` union is a pragmatic compromise; improvement is nice-to-have
