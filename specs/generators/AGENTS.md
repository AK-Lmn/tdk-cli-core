# AGENTS.md - Configuration Generators

## Purpose

Generate all configuration files for services: Vite, TSConfig, npmrc, nginx, Prisma, etc.

## Key Files

### Main Generators
- **`vite_config.star`** - Vite configs (local, Docker, production)
- **`tsconfig.star`** - TypeScript configuration with paths
- **`npmrc.star`** - npm/bun registry configuration
- **`nginx_conf.star`** - Nginx reverse proxy configs

### Specialized
- **`typescript/prisma_config.star`** - Prisma client configuration
- **`typescript/backend_tsconfig.star`** - Backend-specific TSConfig
- **`typescript/frontend_tsconfig.star`** - Frontend-specific TSConfig
- **`vite/backend.star`** - Vite config for backends
- **`vite/frontend.star`** - Vite config for frontends
- **`vite/library.star`** - Vite config for libraries
- **`vite/sdk.star`** - Vite config for SDKs

### Utilities
- **`validators.star`** - Config validation
- **`index.star`** - Generator exports

## Common Tasks

### Generate all configs for service
```starlark
load("./vite_config.star", "generate_for_manifest")
load("./tsconfig.star", "generate_backend")
# Called automatically by ManifestResource
```

## Integration

- Called by `resources/orchestrator/generators/manifest_resource.star`
- Each service gets a "config-gen" Tilt resource that runs these generators
- Outputs to services' `autogenerated/` directories

## Output Files

For each service, generates:
- `vite.config.ts` / `vite.config.docker.ts`
- `tsconfig.json` with proper paths
- `.npmrc` for Verdaccio
- `nginx.conf` (if needed)
- Prisma configs

## Important

Generators read the service's `manifest.json` to determine what to generate.
